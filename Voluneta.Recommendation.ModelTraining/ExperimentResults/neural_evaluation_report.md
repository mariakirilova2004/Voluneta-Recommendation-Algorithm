# Neural Network Evaluation Report

## Configuration

- Synthetic samples per run: 1000
- Seeds: 1, 7, 42, 123, 2026
- Dataset split: 70% training / 15% validation / 15% testing (existing `DatasetSplitter` defaults)
- Models compared: Mean Rating Baseline, Linear Score Baseline, Custom Neural Network
- Neural network training defaults: existing `NeuralNetworkTrainer`/`TrainingOptions` defaults used by `ModelComparisonExperiment` (no hyperparameter tuning performed on test data)

## Methodology

For each seed, a fresh synthetic dataset is generated and split into training/validation/testing
subsets using the existing `SyntheticDatasetGenerator` and `DatasetSplitter`. Each model is fit
only on the training subset and evaluated once on the held-out testing subset via the existing
`ModelEvaluator`. No model or hyperparameter selection is performed using the test subset.
Per-seed results are aggregated with the existing `StatisticsCalculator` (mean and sample
standard deviation across the 5 seeds).

**Important:** All rating targets used here are synthetically generated by
`SyntheticTargetGenerator`/`SyntheticDatasetGenerator`, not collected from real volunteers or
causes. Results describe how well each model fits this synthetic data-generating process, not
real-world volunteer satisfaction.

## Interpretation

Across the 5 seeds evaluated, **Neural Network** achieved the lowest mean MAE
(0.0408 normalized, 0.3671 on the 1-10 scale). This report presents
the measured results as-is; it does not assume in advance that the neural network outperforms
the baselines, and in some configurations a baseline may perform comparably or better.

## Limitations

- Targets are synthetically generated (`SyntheticTargetGenerator`), not collected from real volunteers or causes.
- Results reflect how well each model recovers the synthetic scoring function plus injected noise, not real-world recommendation quality.
- No hyperparameter tuning was performed on the test subset; reported numbers use existing training defaults.
- Only 5 seeds were evaluated; variance estimates are based on this small sample of runs.
